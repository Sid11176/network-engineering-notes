## 🔄 Loopback Interfaces: A Quick Refresher

- **What is it?** A virtual interface in the router.
- **Key Characteristic:** It is always in an **up/up** state (unless manually shut down).
- **Purpose:** Provides a stable, consistent IP address to identify and reach the router, regardless of the status of physical interfaces. This is crucial for router IDs and management.

## 🌐 OSPF Network Types

The network type defines how OSPF operates on a specific link.

### 1. Broadcast Network Type

- **Default On:** Ethernet, FDDI.
- **Key Behaviors:**
    - **Dynamic Neighbor Discovery:** Routers automatically find neighbors using multicast Hello messages (224.0.0.5).
    - **DR/BDR Election:** A Designated Router (DR) and Backup Designated Router (BDR) are elected on the segment.
    - **Full Adjacencies:** All routers form a full adjacency with the DR and BDR. DROthers only form a 2-Way state with each other.

#### 📌 DR/BDR Election Process

1. **Highest OSPF Interface Priority** becomes the DR. (Default = 1).
2. **Tie-breaker:** If priorities are equal, the highest **OSPF Router ID** becomes the DR.
3. **Second Place:** The router with the second-highest priority/ID becomes the BDR.
4. **Non-Preemptive:** The DR and BDR roles **do not change** if a new router with a higher priority/ID joins the segment. They keep their roles until the OSPF process is reset or the interface fails/goes down.
5. **DR Failure:** If the DR fails, the **BDR immediately takes over** as the new DR. An election is then held for the new BDR.

### 2. Point-to-Point Network Type

- **Default On:** Serial interfaces using PPP or HDLC encapsulation.
- **Key Behaviors:**
    - **Dynamic Neighbor Discovery:** Still uses multicast Hello messages (224.0.0.5).
    - **No DR/BDR:** A DR/BDR election is **NOT** held. This is because there can only be two routers on the link, so the election is unnecessary. The two routers form a full adjacency directly.

---

## 📜 Serial Connections (Brief Overview)

- **Layer 2 Encapsulation:** HDLC (Cisco default) or PPP.
- **Key Concept:** One side of the link is **DCE** (Data Communications Equipment) and the other is **DTE** (Data Terminal Equipment).
- **Clock Rate:** The DCE side is responsible for providing the clock rate (speed) for the connection.

## 🤝 OSPF Neighbor & Adjacency Requirements

For two routers to become OSPF neighbors, they must meet several requirements. While you don't need to memorize the list, you must be able to identify and fix these issues when troubleshooting.

- **1. Area Number:** Interfaces must be in the same OSPF area.
- **2. Subnet:** Interfaces must be in the same IP subnet.
- **3. OSPF Process:** The OSPF process must not be `shutdown`.
- **4. Router ID:** OSPF Router IDs must be unique.
- **5. Hello/Dead Timers:** Timers must match on both routers.
- **6. Authentication:** Authentication settings and passwords must match.
- **7. MTU (Maximum Transmission Unit):** IP MTU sizes must match.
    - **⚠️ Caveat:** Neighbors can still form, but will get stuck in the **EXSTART** state and fail to exchange LSAs.
- **8. OSPF Network Type:** Network types must match.
    - **⚠️ Caveat:** Neighbors can still form and show as **FULL**, but OSPF will not function correctly (e.g., routes won't be properly added to the routing table).

## 🗃️ OSPF LSA (Link State Advertisement) Types

The LSDB is made of LSAs. All routers in an area share the same LSDB.

| Type | Name | Description | Generated By |
| --- | --- | --- | --- |
| **1** | **Router LSA** | Identifies a router (via Router ID) and lists its directly connected, OSPF-activated networks. | Every OSPF Router |
| **2** | **Network LSA** | Lists the routers attached to a multi-access network (like Ethernet Broadcast). | The DR of a segment |
| **5** | **AS-External LSA** | Describes routes to destinations outside the OSPF autonomous system (e.g., a default route to the internet). | An ASBR (Autonomous System Boundary Router) |

## ⌨️ Syntaxes Used (Categorized by Lesson Topic)

### 📍 From "Broadcast Network Type & DR/BDR Election"

| Syntax | Description | Mode |
| --- | --- | --- |
| `ip ospf priority <0-255>` | Sets the OSPF priority for an interface. A value of 0 means the router cannot become DR/BDR. | Interface Config |
| `show ip ospf interface [brief]` | Displays OSPF settings for one or all interfaces (Priority, State, Neighbor Count, etc.). | Privileged EXEC |
| `show ip ospf neighbor` | Displays the OSPF neighbor table, including state (FULL, 2-Way, etc.). | Privileged EXEC |
| `clear ip ospf process` | Resets the OSPF process, forcing a new DR/BDR election and clearing neighbor adjacencies. | Privileged EXEC |

### 📍 From "Point-to-Point Network Type & Serial Connections"

| Syntax | Description | Mode |
| --- | --- | --- |
| `clock rate <speed>` | Sets the speed for a serial connection on the DCE side. | Interface Config |
| `encapsulation ppp` | Changes the Layer 2 encapsulation on a serial interface from the default HDLC to PPP. | Interface Config |
| `show interface <interface-id>` | Verifies interface status, encapsulation type (HDLC/PPP), and other settings. | Privileged EXEC |
| `show controllers <interface-id>` | Verifies which side of a serial link is DCE and which is DTE. | Privileged EXEC |
| `ip ospf network <type>` | Manually configures the OSPF network type on an interface (e.g., point-to-point). | Interface Config |

### 📍 From "OSPF Neighbor & Adjacency Requirements"

| Syntax | Description | Mode |
| --- | --- | --- |
| `shutdown` / `no shutdown` | Shuts down or enables the OSPF process (when in OSPF config mode). | OSPF Config |
| `router-id <A.B.C.D>` | Manually configures the OSPF Router ID. | OSPF Config |
| `no router-id [A.B.C.D]` | Removes the manually configured Router ID, reverting to the automatic selection. | OSPF Config |
| `ip ospf hello-interval <seconds>` | Configures the OSPF Hello timer on an interface. | Interface Config |
| `ip ospf dead-interval <seconds>` | Configures the OSPF Dead timer on an interface. | Interface Config |
| `no ip ospf hello-interval [seconds]` | Returns the Hello timer to its default value. | Interface Config |
| `no ip ospf dead-interval [seconds]` | Returns the Dead timer to its default value. | Interface Config |
| `ip ospf authentication-key <password>` | Sets the OSPF password on an interface. | Interface Config |
| `ip ospf authentication` | Enables OSPF authentication on an interface. | Interface Config |
| `ip mtu <bytes>` | Sets the IP Maximum Transmission Unit size on an interface. | Interface Config |
| `no ip mtu` | Returns the IP MTU to its default value. | Interface Config |

### 📍 From "LSA Types"

| Syntax | Description | Mode |
| --- | --- | --- |
| `default-information originate` | Advertises a default route into the OSPF domain (used on an ASBR). | OSPF Config |
| `show ip ospf database` | Displays the OSPF Link State Database (LSDB). | Privileged EXEC |

**Question 5**
R1 is connected to an OSPF Broadcast network on its G0/0 interface. R4 is the DR of the segment and R3 is the BDR. All routers have the default OSPF priority. You issue the `ip ospf priority 100` command on R1's G0/0 to make it the DR. Which two statements are true about the network after you issue the command? (Select two)
A. R1 is the DR.
B. R1 is the BDR.
C. R1 is still a DROther because its priority isn't high enough.
D. If you issue the `clear ip ospf process` command on R4, R1 will become the BDR.
E. If you issue the `clear ip ospf process` command on R4, R1 will become the DR.
F. The DR and BDR of the network are unchanged.

---

### ✅ Quiz Answers

1. **B.** In the OSPF point-to-point network type, DR and BDR elections are not held.
2. **C.** The DR forms a FULL adjacency with all other routers in the segment.
3. **A & D.** For two routers to become OSPF neighbors, the Hello and Dead timers on their interfaces must match, and they must be in the same area.
4. **B.** Type 2 is the 'Network' LSA, generated by the DR of each multi-access network.
5. **D & F.** The DR and BDR will not automatically give up their positions (non-preemptive), so R1 remains a DROther. However, if you clear the OSPF process on the DR (R4), the current BDR (R3) becomes the new DR, and a new election is held for the BDR. Since R1 has the highest priority, it will become the new BDR.
